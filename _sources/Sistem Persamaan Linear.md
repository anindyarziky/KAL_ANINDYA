# Definisi Sistem Persamaan Linear
Sistem persamaan linear adalah sekumpulan persamaan linear yang terdiri dari beberapa variabel. Sistem ini terdiri dari tiga persamaan dengan tiga variabel yaitu x, y, z. Sistem ini digunakan untuk mencari nilai variabel yang memenuhi semua persamaan dalam sistem tersebut secara bersamaan.
# Jenis - Jenis Sistem Persamaan Linear 
## Sistem Persamaan Linear Satu Variabel
Seperti dengan namanya, persamaan linear satu variabel tersebut akan memiliki satu variabel dengan pangkat 1. 
Contoh: 
*         ax + b = 0

## Sistem Persamaan Linear Dua Variabel 
 Persamaan linear dua variabel ini adalah sistem persamaan yang memiliki variabel berjumlah dua dengan pangkat 1.
Contoh: 
*          ax + by = c
 ## Sistem Persamaan Linear Tiga Variabel
 Sistem persamaan yang terdiri dari tiga persamaan linear dengan tiga variabel yang saling berhubungan.
Contoh:
*         ax + by + cy = d
# Ciri-ciri Sistem Persamaan Linear 
1. Persamaan linear akan memiliki pangkat satu.
2. Persamaan linear tidak memiliki perkalian variabel.
3. Membentuk garis lurus 
# Jenis Solusi 
## Satu Solusi 
Jika persamaan saling berpotongan pada satu titik. Pada kondisi ini dua garis saling berpotongan. 
## Tidak Ada Solusi
Jika grafik persamaan linear sejajar, maka sistem persamaan linear tidak memiliki solusi. Dalam hal ini, tidak ada titik yang tidak ada garis yang saling berpotongan. 
## Solusi Tak Terhingga
Persamaan linear dengan dua variabel memiliki solusi tak terhingga. Grafik untuk sistem persamaan linear dengan solusi tak terhingga adalah grafik garis lurus yang saling tumpang tindih.
